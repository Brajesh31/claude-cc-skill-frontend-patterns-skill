# Cc Skill Frontend Patterns

Frontend development patterns for React, Next.js, state management, performance optimization, and UI best practices.

## Overview

This repository preserves the AITMPL skill instructions and its published companion resources.

## Installation

```bash
git clone https://github.com/Brajesh31/claude-cc-skill-frontend-patterns-skill.git ~/.claude/skills/cc-skill-frontend-patterns
```

On Windows, use `%USERPROFILE%\.claude\skills\cc-skill-frontend-patterns` as the destination.

## Usage

Claude Code can load this skill when a request matches its description. Invoke directly with `/cc-skill-frontend-patterns` when needed.
